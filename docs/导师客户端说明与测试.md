# 导师交互与客户端验证

郭冀康负责 Unity 导师界面、指导请求、场景定位、客户端证据和练习回顾。当前代码可以在丁书萱的现代厨房中独立运行。默认进入六步联调，桌面用户能点击模拟动作，也能在开火阶段点击厨房里的真实旋钮。热锅小样保留五秒提醒，用于观察导师出现的时机。

## 用户经历什么

开始练习时显示菜名、当前步骤、六个进度标记和一张可收起的导师卡。玩家可以先打蛋，也可以先切番茄。卡片支持主动求助和自由文字追问，指导响应等待期间可以取消，操作控件暂停，失败时可以重试。若回复给出有效物体，Unity 在实际位置显示提示圈；操作进展、取消后重新发问或重置都会使过期引导失效。

完成六步后，回顾根据固定菜谱展示可复制的现实做饭清单，根据本轮已收到的操作和请求统计受阻次数和主动求助次数。系统自动纠错、同一求助的网络重试均不增加主动求助次数。从“其他动作”点“重新开始”或在完成后点“再练一次”时使用新的会话编号。导出记录位于 Unity 的 `Application.persistentDataPath/CookCoach-Evidence`，界面会显示具体文件路径。

## 一次指导如何执行

1. 流程模块发布当前菜谱、会话、状态版本和近期操作。导师只在单条指导请求完成或取消后接受下一条。
2. 出错、点击提示和输入追问共用指导接口。客户端发送当前状态、有限长度的对话和已注册物体。客户端拒绝过期会话、旧版本或编号不匹配的回复。
3. 成功响应保留来源与文字。目标必须在请求发出时列入允许集合，且在执行时仍然注册、存在并处于活动状态。更新场景和重置练习时清除旧高亮。
4. 右上角“交互记录”可查看最近活动、当前请求与回复。导出 JSON 包含本轮全部事件、请求载荷、响应、目标、执行结果和客户端耗时。实际操作的 `previous_guidance_id` 指向此前最近一次已呈现的指导，便于核对提醒后的纠正。客户端耗时包含网络等待；后台模型耗时由模型服务记录。
5. 模拟动作、模拟回复、备用回复和实际模型回复分别留有来源字段。公开演示材料须按真实来源标注。

## 本地复验

1. 在仓库根目录运行 `python tools/tutor_fixture.py`。该服务只绑定本机 18741 端口，不使用密钥。浏览器打开 `http://127.0.0.1:18741/health` 可看到测试来源 mock。
2. 在 Unity 打开 `Assets/Scenes/KitchenTutorPractice.unity` 并进入 Play，另起一轮测试练习。使用菜单 **CookCoach → 验证导师客户端（本地 HTTP 测试服务）**。该菜单会重置当前模拟练习；需要保留的体验记录可先导出。
3. 等待超时分支结束。在 Console 按 `[TutorCheck]` 过滤。逐项检查输出 PASS；全部通过时输出 COMPLETE。EVIDENCE 行提供本轮 JSON 路径。测试结束会恢复原指导模式、接口地址和练习起点。
4. 手动复验时通过“其他动作”先打蛋，再切番茄，再从“其他动作”点“炒蛋并盛出”，等待导师回应后询问“开关在哪里？”。点击圈内旋钮再问“现在呢？”。完成菜谱后核对回顾，以及导出文件中的 request_id。
5. 替换为真实服务时把 KitchenTutor 组件的 Mode 设为 Http，Endpoint 指向实际的指导接口，并以真实模型日志和相同 request_id 复核。

## 本轮结果与报告边界

2026 年 11 月 22 日，本机在 Unity 6.6（6000.6.4f1）桌面预览工程中通过 19 项客户端检查。通关与错误路径使用模拟厨房动作，网络用例实际通过 UnityWebRequest 调用本机 Python 测试服务。团队工程指定 2022.3.62f1，原版本回归、正式食材表现、真实模型输入输出与真实学习效果仍待验证。

| 核对内容 | 实测结果 |
|---|---|
| 六步顺利完成 | 回顾显示 0 次受阻、0 次主动求助 |
| 交换两个备料步骤，重复提交同一操作 | 两个准备阶段分别记录一次 |
| 未开火尝试炒蛋 | 产生受阻事件，等待回复时不能推进厨房动作 |
| 追问开关位置 | 请求携带上一轮交流，已注册的旋钮出现高亮；请求与执行记录可按编号关联 |
| 开火后再次提问 | 高亮清除，发送的新快照显示炉灶已开启 |
| 完成并导出 | 清单包含六步，实测错误路径统计 1 次受阻、2 次主动求助；重新读入 JSON 后记录完整 |
| 异常目标、错误状态版本、损坏的 JSON | 非法高亮被忽略，无效回复进入可恢复的失败状态 |
| 服务返回 503、重试、备用回复 | 失败解除等待，重试生成新请求号且不增加求助次数，备用回复单独标记 |
| 取消、等待中重置、20 秒超时 | 迟到的回复不覆盖新练习；超时后恢复输入 |
